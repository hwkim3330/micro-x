로컬 학습 실행

로컬 서버에 연결되지 않았습니다. 아래 순서대로 실행하면 이 화면에서 학습을 시작할 수 있습니다.

  1. uv venv --python 3.12 .venv-policy && uv pip install --python .venv-policy/bin/python -r requirements-policy.txt
  2. .venv-policy/bin/python tools/fetch_compat.py · 공식 추론 코드와 가중치를 로컬 캐시에 내려받습니다.
  3. .venv-policy/bin/python runtime/training_service.py 후 127.0.0.1:5201 접속.


체크포인트
로컬 서버에 연결되면 저장된 ONNX가 여기에 나타납니다.


평가 결과 비교
새 초기 조건(시드 10부터)으로 정지·전진 0.1/0.3 m/s·회전 0.3 rad/s 명령을 각 시드마다 실행합니다. 통과 기준: 넘어짐 없음, 전진 오차 ≤ max(0.03, 명령의 25%), 좌우 ≤ 0.03 m/s, 회전 ≤ 0.10 rad/s.



보행 기록을 실제 CAD 위에서
공식 가중치로 계산한 시뮬레이션 기록(0.3 m/s 전진 명령)을 관절 각도 그대로 재생합니다. 학습한 체크포인트 기록은 로컬 서버의 보행 실험 화면에서 재생하세요.

가상 턱 서보 학습 (교육용 1축)
목표 각도에 도달하도록 제어 계수 두 개를 직접 학습합니다. CEM이 후보를 평가하고 오차가 작은 정책을 남깁니다. 브라우저 안에서만 실행되는 입문용 예제입니다.
아직 학습하지 않았어요.
별도 목표 3개에서 각도 RMSE—
정규화된 1축 교육용 환경입니다. 실제 모터·하중 모델이나 보행 학습이 아니며 정책은 이 환경에서만 실행됩니다.



목소리와 표정
문장을 읽으며 공룡의 턱(15번째 서보)이 움직여요. 브라우저 음성 합성을 사용하는 표현 미리보기입니다.
마이크 입력이나 AI 대화 서버를 사용하지 않습니다.
음성 지원은 브라우저에 따라 다릅니다. 턱 움직임은 표현용 애니메이션이며 정밀한 음소 동기화가 아닙니다.
