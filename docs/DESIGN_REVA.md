# Micro X Rev A — 구동 기구가 들어간 치비 티렉스

Rev A는 P0 외형 모델을 폐기하고 **15개 XL330급 서보, 배터리, 컴퓨트 보드, 카메라가 실제로 들어가는 자리**까지 그린 첫 구동 설계입니다. 사용자 요청은 두 가지였습니다: 원본 Microduck 수준으로 귀엽게, 그리고 상업용 독자 설계로. 비율은 치비(머리 > 몸, 통통한 발)로 잡고, 관절 배치는 Microduck의 14축 정책 인터페이스를 그대로 유지했습니다.

전체 좌표는 mm, X 앞, Y 왼쪽, Z 위, 바닥 Z=0, 몸통 기준점 Z=125입니다. 생성기는 `cad/build.py`, 관절 배치는 `cad/layout.py`, 서보 인터페이스는 `cad/servo.py`입니다.

## 비율과 외장

| 요소 | Rev A | 근거 |
|---|---|---|
| 머리 | 타원체 100 × 80 × 74 mm + 주둥이 48 × 64 × 50 mm | 원본 Microduck 머리(약 90 × 70 × 50)보다 크고 둥근 치비 비율; 요·롤 서보와 턱 서보가 안에 들어감 |
| 눈 | Ø30 돔 × 2, 뒤쪽 M3 나사 고정 | 눈동자·하이라이트는 도색 표현 |
| 몸통 | 알 모양 108 × 78 × 88 mm, Z 121 아래 개방 + 양쪽 다리 개구 | 고관절 요·롤 기구가 아래에서 회전; 가슴 그릴 뒤에 보드 |
| 다리 | 허벅지·종아리에 서보 포켓, 발 82 × 48 mm | 발목 서보는 종아리 안에 15° 앞으로 기울여 세워 무릎 서보와 간섭 없이 발이 ±30° 회전 |
| 꼬리 | 배터리 커버 | NP-F550급 배터리가 꼬리 안으로 들어가고 두 개의 M3로 트레이에 고정 |
| 배색 | 크림 쉘 + 코랄 발·아래턱 + 그래파이트 관절 | 두 톤 + 어두운 관절로 Microduck과 같은 문법 |

## 서보 배치 원칙

각 관절에서 서보 **몸체는 한쪽 링크의 포켓에 앉고**, 다른 쪽 링크는 **혼(출력)과 아이들러(뒷면) 두 판**으로 양쪽에서 잡습니다. 그래서 모든 관절이 양단 지지입니다.

| 관절 | 서보 몸체 위치 | 판을 가진 링크 | 비고 |
|---|---|---|---|
| 고관절 요 | 몸통 섀시 행어 | 요·롤 브래킷 | 혼 아래 방향, 선택적 16×22×4 베어링 자리 |
| 고관절 롤 | 요·롤 브래킷 | 고관절 브래킷 | 롤 범위 HOME ±10°(원본 ±22°)로 제한해 반대쪽 고관절과 몸통 쉘 간섭 회피 |
| 고관절 피치 | 허벅지 컵 | 고관절 브래킷 | 컵 위에 캡, 브래킷은 캡 위로 타이 |
| 무릎 | 종아리 | 허벅지 | 종아리 척추판이 무릎·발목 서보를 함께 잡음 |
| 발목 | 종아리 (15° 기울여 세움) | 발 | 무릎 서보와 2 mm 간격, 발 회전 여유 확보 |
| 목 피치 | 몸통 섀시 | 목 링크 | HOME(+0.35 rad)에서 뒤로 -0.2 rad까지(몸통 지붕 간섭); 지붕 슬롯으로 확보 |
| 머리 피치 | 목 링크 | 머리 베이스 | |
| 머리 요 | 요크 (자식) | 머리 베이스 | 요 서보가 머리와 함께 돌아 머리 내부가 비워짐 |
| 머리 롤 | 요크 | 머리 프레임 | 롤 서보 장축을 Y로 놓아 두개골 안에 들어감; 롤 ±12° |
| 턱 | 머리 프레임 | 아래턱 | 15번째, 정책 외 축; 개구 0.35 rad(20°) — 더 열면 부리 뒤끝이 서보를 침 |

혼·아이들러 볼트 패턴(Ø12 원 위 4×M2)과 몸체 치수는 구매품 데이터이며 `engineering/actuator_interface.json`에 출처와 **발주 전 확인 항목**을 적었습니다. 케이스 측면 홀은 아직 모델에 없어 몸체 고정은 포켓 벽과 이웃 판의 볼트에 의존합니다.

## Microduck 대비 개선 목표 (설계 의도, 실측 전)

1. **정비성**: 배터리는 꼬리 커버, 보드는 몸통 쉘(M3 4개)을 벗기면 바로 보이는 가슴 벽, 두개골은 두 개의 M3로 프레임 레일에 고정. 서보 교체 시 혼·아이들러 볼트 8개만 풂.
2. **표정**: Ø30 돔 눈 두 개 + 코 카메라 한 개를 분리해 카메라가 눈처럼 보이지 않게 함. 아래턱은 서보로 움직임.
3. **발**: 넓고 둥근 발(82 × 48)로 정적 여유를 키우고 바닥을 비워 TPU 패드를 끼울 수 있게 함.
4. **투명한 검증**: 정적 간섭·관절별 가동 샘플·공식 가중치 시뮬레이션 결과를 저장소에 고정하고 웹에서 재생.

원본과 비교한 속도·안정성·배터리 시간의 우위는 실물 시험 전이므로 주장하지 않습니다.

## 디지털 검증 상태

- 21개 출력 부품 모두 STEP 왕복·닫힌 메시 통과. 질량 421.6 g(PLA 꽉 찬 기준), 구매품 404 g, 모델 총 825 g. `artifacts/parts.json`, `artifacts/balance.json`.
- 정적 간섭: HOME 자세에서 출력 부품·서보 외형·배터리·보드·카메라 상호 겹침 검사 (`artifacts/interference.json`).
- 가동 간섭: 관절별 샘플 각도(고관절 요 ±0.4, 롤 ±0.17, 피치 ±0.7, 무릎 ±0.5, 발목 ±0.5, 목 -0.2/+0.4, 머리 피치 ±0.6, 요 ±1.2, 롤 ±0.2, 턱 0.35 rad)에서 하위 트리를 회전시켜 재검사. **현재 충돌 샘플 0.** 큰 무릎 굽힘(>0.5 rad)에서는 기울인 발목 서보가 허벅지에 닿으므로 무릎 범위를 정책에서 제한해야 합니다.
- 동역학: `cad/compat_model.py`가 부품 메시로 질량·관성을 계산해 `models/micro_x_14.xml`을 생성. 공식 가중치 시험은 `artifacts/compat_evaluation.json`.
