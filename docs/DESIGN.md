# Micro X Rev B — 설계

Rev B는 Rev A를 버리고 **기준 로봇의 관절 배치를 측정해 그 위에 처음부터 다시 그린 설계**입니다. 바뀐 것은 세 가지입니다.

1. **설계 자세를 바꿨습니다.** 예전에는 HOME 자세(다리가 굽은 자세)에서 치수를 쟀기 때문에 모든 피벗 축이 5° 기울어 있었고, 브래킷마다 기울어진 형상이 필요했습니다. Rev B는 `qpos = 0`(다리가 곧게 선 자세)에서 측정합니다. 그래서 **모든 관절 축이 X·Y·Z에 정렬**되고, 브래킷이 전부 단순한 직육면체 조합이 되어 서포트 없이 평평하게 출력됩니다. 정책의 HOME 각도는 기구에 굳히지 않고 그냥 관절 각도로 둡니다.
2. **서보 고정 방식을 기준 로봇과 같게 했습니다.** Rev A는 관절마다 판 두 장으로 서보를 감싸는 클레비스 구조여서 부피가 크고 서보가 밖으로 드러났습니다. Rev B는 **서보 몸체가 한쪽 링크의 U자 채널에 들어가고, 이웃 링크는 혼에 볼트로 붙는 판 한 장**입니다. 부품이 얇아지고 가벼워졌습니다(출력물 422 g → 347 g).
3. **가동 범위를 추측하지 않고 측정합니다.** `tools/travel.py`가 관절마다 0.05 rad씩 돌려 가며 정확한 STEP 불리언으로 충돌을 찾아 **실제로 움직일 수 있는 각도**를 구하고, 그 값이 그대로 MuJoCo 관절 한계가 됩니다.

좌표계는 mm, X 앞, Y 왼쪽, Z 위, 바닥 Z=0, 몸통 기준 프레임 Z=120입니다. 생성기는 `cad/build.py`, 배치는 `cad/layout.py`, 서보 인터페이스는 `cad/servo.py`, 측정값은 `engineering/functional_layout.json`입니다.

## 구성

| 부위 | 내용 |
|---|---|
| 몸통 | 섀시(바닥판·고관절 요 서보 박스 2개·전장 데크·배터리 트레이) + 알 모양 쉘(아래는 직선 통, 위는 돔) |
| 꼬리 | 배터리 커버. 2S 18650급 팩(65 × 37 × 19)이 들어가고 M3 2개로 트레이에 고정 |
| 다리 | 요·롤 브래킷 → 고관절 브래킷 → 허벅지 쉘(고관절 피치 + 무릎 서보) → 종아리(발목 서보) → 발 |
| 목 | 두 서보가 세로로 쌓인 튜브 + 둥근 커버. 커버는 목과 함께 기울어짐 |
| 머리 | 요크(머리 요 서보) → 머리 프레임(머리 롤 + 턱 서보, 카메라 벽, 두개골 보스) → 두개골 로프트 + 아래턱 |

두개골은 타원체가 아니라 **단면 7개를 잇는 로프트**입니다. 서보가 있는 뒤쪽은 넓고 주둥이로 갈수록 좁아져서 티렉스 머리 실루엣이 나옵니다. 눈·손·발톱 같은 **떨어질 부품은 없습니다.** 눈은 도색, 카메라는 주둥이 끝 렌즈 후드 안에 있습니다.

## 서보 15개의 자리

| 관절 | 서보 몸체가 있는 링크 | 혼 판을 가진 링크 |
|---|---|---|
| 고관절 요 | 몸통 섀시 | 요·롤 브래킷 |
| 고관절 롤 | 요·롤 브래킷 | 고관절 브래킷 |
| 고관절 피치 | 허벅지 | 고관절 브래킷 |
| 무릎 | 허벅지 | 종아리 |
| 발목 | 종아리 | 발 |
| 목 피치 | 목 튜브 | 몸통 섀시 |
| 머리 피치 | 목 튜브 | 머리 베이스 |
| 머리 요 | 요크 | 머리 베이스 |
| 머리 롤 | 머리 프레임 | 요크 |
| 턱 | 머리 프레임 | 아래턱 |

피벗과 축은 기준 로봇 측정값 그대로입니다. 서보 **몸체 방향**만 두 곳에서 바꿨고(`design_servo_overrides`), 이유를 파일에 적었습니다: 머리 롤 서보는 장축을 세워 좁은 뒤통수에 넣었고, 턱 서보는 넓은 쪽으로 향하게 해 부리 팔이 머리 요 서보를 피하도록 했습니다.

## 측정된 가동 범위

`engineering/joint_travel.json`. 왼쪽/오른쪽이 다른 것은 실제로 다르기 때문입니다(브래킷이 좌우 대칭이라 회전 방향에 따라 닿는 곳이 다름).

| 관절 | 측정 가동 범위 | 서보 정격 기준 |
|---|---|---|
| 고관절 요 | -26° … +30° | ±30° |
| 고관절 롤 | -20° … +17° | ±23° |
| 고관절 피치 | -90° … +63° | ±90° |
| 무릎 | -90° … +63° | ±90° |
| 발목 | ±52° | ±90° |
| 목 피치 | -12° … +40° | ±60° |
| 머리 피치 | ±34° | ±90° |
| 머리 요 | ±115° | ±115° |
| 머리 롤 | ±17° | ±25° |
| 턱 | 0° … +17° | 0…40° |

목 피치와 턱이 가장 좁습니다. 목은 서보가 세로로 쌓여 몸통 지붕과 가깝고, 턱은 부리가 카메라 벽에 닿습니다. 다음 개선 대상입니다.

## 출력 (artifacts/printability.json)

20개 부품 모두 220 × 220 침대에 들어갑니다. 최대 오버행 면적 비율은 27 %이고, 부품마다 출력 방향이 `models/print/`에 고정되어 있습니다. 대부분의 브래킷은 면 하나를 침대에 붙이고 벽이 전부 수직이라 서포트가 필요 없습니다. 몸통 쉘은 열린 쪽을 아래로 놓아 테두리 467 mm²가 침대에 닿습니다. 아래턱과 꼬리는 곡면이라 브림이 필요합니다.

## 검증 상태

- 20개 출력 부품 모두 STEP 왕복·닫힌 메시 통과, 347 g(PLA 꽉 찬 기준). 구매품 18개 399 g. 모델 총 746 g (Microduck 780 g).
- 설계 자세 정적 겹침 **0건**, 측정 가동 범위 안의 관절별 샘플 충돌 **0건** (`artifacts/interference.json`).
- HOME 자세 기립 높이 119.3 mm, 무게중심 141 mm, 발 지지영역 안 여유 12.2 mm (`artifacts/balance.json`).
- 변경 없는 공식 보행·서기 가중치를 CAD 기반 14축 모델에서 실행: 15회 모두 10초 직립, 속도·방향 기준은 정지·서기 6회만 통과 (`artifacts/compat_evaluation.json`).
