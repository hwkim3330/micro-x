## 확인한 구조

가상 감각 입력 → 단순화한 신경 활동 계산 → 전진·회전 명령 → 공식 보행 ONNX → MuJoCo 물리 계산 순서입니다. 신경 연결망의 가중치는 이 앱에서 학습하지 않습니다. 공식 정책이 균형과 걸음을 담당합니다. 신경 출력을 직접 14개 모터 목표에 연결하는 별도 경로에는 학습된 균형 제어가 없으며, 작성자의 시험에서도 넘어짐이 기록됐습니다. 이것을 생물학적으로 검증된 뇌나 학습된 자율 탐색으로 설명하지 않습니다.

X에 참고할 것은 **행동을 고르는 기능과 균형을 잡는 기능의 분리**, 실제 물리 상태에 연결된 화면, 중지·리셋·입력 차단을 확인할 수 있는 실험 방식입니다. 별도 다운로드한 원본 연결망을 실행하고 X 물리 상태를 감각 입력으로 돌려주는 실험용 어댑터를 구현했습니다. 제품용 통합 완료를 뜻하지 않습니다.

## X 적용 순서

먼저 전진·회전 명령을 추종하는 보행 정책을 확보합니다. 그 위에 카메라 인식으로 관심 대상을 선택하고 속도·회전 명령을 만드는 행동 계층을 붙입니다. 거리·방향 측정과 명령 변환은 별도 시험하고, 센서가 오래되거나 목표가 사라지면 정지 명령으로 돌아가게 합니다. 단안 카메라만으로 거리 정확도가 확보된다고 가정하지 않습니다.

뇌 시각화나 원본 로봇 외형을 제품에 복사하는 것은 현재 범위가 아닙니다. Microfly의 앱 라이선스와 포함된 로봇·뇌 조직 메시·원본 데이터의 조건은 각각 확인해야 하며, 앱 표기만으로 X의 상업용 재배포 권리를 판단하지 않습니다. 현재 X에는 Microfly의 자산·연결망·코드를 포함하지 않았습니다.


## 직접 실행한 결과

원본 Microfly 소스의 단위 검사 9개와 브라우저 검사를 실행했습니다. 원본 Microduck은 171 제어 스텝 동안 넘어지지 않고 경로 길이 0.222 m를 이동했습니다. 좌우 가상 냄새에 따른 회전 반전, 냄새 제거 시 이동 명령 정지, 연결 차단, 일시정지·리셋·모바일 검사가 통과했습니다. 직접 모터 모드는 정책 호출 0회를 확인했지만 넘어졌으므로 보행 방식으로 채택하지 않습니다.

X에는 139,255개 뉴런·2,698,236개 연결의 전체 제공 그래프를 사용했습니다. 10초씩 좌/우 목표, 냄새 없음, 시냅스 차단, 출력 연결 해제를 실행했습니다. 좌우 조건의 명령은 발생했고 차단 조건은 0이었습니다. X는 넘어지지 않았지만 순이동은 약 1 cm에 불과해 탐색·보행 합격으로 판정하지 않았습니다. 가상 냄새는 위치로 계산하며 실물 냄새 센서를 뜻하지 않습니다. 신경 가중치 학습도 하지 않았습니다.

원본 브라우저는 XML 위치 액추에이터를 사용하고 X 서버는 BAM M6를 사용합니다. 이 차이를 줄이기 위해 X에서 생성된 동일 명령을 원본 `robot_walk.xml`과 X에 같은 Python 정책/BAM 조건으로 재생했습니다. 오른쪽 목표 조건의 순이동은 원본 약 0.439 m, X 약 0.012 m였고 양쪽 모두 넘어지지 않았습니다. 왼쪽 조건은 양쪽 약 0.011 m에 머물렀습니다. 이 결과는 X 보행 차이가 남는다는 증거이며 단일 부품을 원인으로 특정하지 않습니다. 원본 비교 XML은 브라우저의 `robot_allcollisions.xml`과 다르고, 한 시드의 명령 재생이므로 원본의 독립적인 냄새 탐색 시험도 아닙니다.

### 재현

기존 정책 의존성을 설치한 뒤, 위에 고정한 Microfly revision의 `flyduck-source.zip`을 별도 폴더에 풉니다. 어댑터는 실행할 신경 코드와 데이터의 SHA-256을 검사합니다. 원본 로봇 자산은 X 저장소에 포함하지 않습니다.

```sh
node tools/evaluate_fly_brain.mjs /path/to/microfly-reference
.venv-policy/bin/python tools/compare_fly_replay.py /path/to/microduck/robot_walk.xml
```

첫 명령은 로컬 포트 5220을 사용합니다. 두 번째 명령은 원본 XML 옆의 메시 파일도 필요합니다. 공개 Pages에서 이 뇌 실험이 실행되는 것은 아니며 현재는 로컬 실험입니다. 다음 합격 조건은 여러 시드에서 전진·회전 추종을 통과한 뒤 목표 접근과 입력 차단을 검증하는 것입니다.
